# Cartora – ecom-website-day-6

React e-commerce demo. Products come from https://fakestoreapi.com.

## Run
```
npm install
npm run dev
```

## Concepts used
- Component-based architecture (`components/`, `pages/`)
- React Router v6 (`/`, `/products`, `/products/:id`, `/cart`, `/checkout`)
- Formik (checkout form with validation)
- Custom hooks (`useFetch`, `useLocalStorage`, `useDebounce`)
- Context API (`CartContext`) for cart state
